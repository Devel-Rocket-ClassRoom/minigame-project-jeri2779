적
-고속 이동 => 고속으로 이동하며 플레이어를 추적
-슈퍼타입 => 전체적인 높은 스탯 타입. 이동속도/체력/공격력이 전부 높음
-높은 체력 => 높은 체력을 가진 타입
- 회복 타입 => 자신 범위 내 주변 적들 체력 일정량 회복
- 방어 타입 => 자신 범위 내 주변 적들 입는 피해량 감소

업그레이드 요소
- 더블점프 ( 점프중 공중에서 한번 더 점프)
- 활공 (점프중 공중에서 가속하며 질주)
- 체력 회복(전투중이 아닐때 체력 회복 => 총기를 발사하지 않을때)
- 탄환 생성(재장전시 추가 탄약 생성 => 30발 탄약짜리 재장전시 40발로 증가)
- 연속 투척(수류탄 투척시 1개 추가 투척 => 수류탄 개수 소모X 
- 머니 파워(소지 재화가 많을수록 피해량 증가 => 최종 대미지에 합산)
- 부스터(권총 기관단총을 꺼내고 이동할시 일정시간마다 이동속도 증가(n초간)
- 투지(적 수가 맵에 많을수록 공격력 증가 => 최종 대미지에 합산
- 인파이터(근접무기 공격력이 증가)
- 돌파(돌격소총(AR) 장착하고 이동할때마다 공격력 일시 증가 이동이 멈출시 효과 일시 제거)
- 치명타(공격시 일정확률로 배수의 대미지를 입힌다.
- 최후의 저항(hp가 일정 이상 떨어질시 무적 효과 돌입 이후 입는 피해량 및 공격력 추가 증가)
- 흡혈(적을 일정수 처치마다 체력 회복)
- 폭발탄(맞은자리 주변에 일정범위의 범위공격판정을 생성하여 대미지를 준다)
